# References and provenance

- Historical architecture: the unchanged [16-slide presentation](../docs/slides.pdf), *3D Scanning framework for iPhone*, by Mohamad Jabareen and Mostafa Agbariah, supervised by Aaron Wetzler. It describes ZIP upload over HTTP, VisualSFM processing, PLY results and KiwiViewer display. A further 39-page 2014 report was recovered privately during the revival; it confirms the same architecture and asynchronous request/result polling. It is not republished because it contains private account/database material. No original application source was recovered.
- COLMAP: [official documentation](https://colmap.github.io/), [PyCOLMAP bindings](https://github.com/colmap/colmap/tree/main/python), [COLMAP license](https://github.com/colmap/colmap/blob/main/COPYING.txt). Tested numerical engine: pycolmap 3.13.0 CPU SIFT → exhaustive matching → geometric verification → incremental mapping → bundle adjustment. The new code orchestrates this engine; it does not reimplement it.
- OpenCV: [StereoSGBM reference](https://docs.opencv.org/4.x/d2/d85/classcv_1_1StereoSGBM.html), [camera calibration and stereo geometry](https://docs.opencv.org/4.x/d9/d0c/group__calib3d.html), [Apache 2.0 license](https://github.com/opencv/opencv/blob/4.x/LICENSE). Tested version 4.12.0.
- Flask: [official documentation](https://flask.palletsprojects.com/), BSD-3-Clause license. Used for the local HTTP service, not a hosted multi-user service.
- Pillow: [official documentation](https://pillow.readthedocs.io/), HPND license. Used for bounded decoding, EXIF orientation and JPEG normalization.
- NumPy: [official documentation](https://numpy.org/doc/), BSD-3-Clause license. Used for coordinate transforms and point filtering.
- Real RGB images: [TUM RGB-D benchmark](https://cvg.cit.tum.de/data/datasets/rgbd-dataset), `rgbd_dataset_freiburg1_xyz`, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Credit Jürgen Sturm, Nikolas Engelhard, Felix Endres, Wolfram Burgard and Daniel Cremers, *A Benchmark for the Evaluation of RGB-D SLAM Systems*, IROS 2012. Reconstruction uses only selected color frames. Withheld motion-capture poses are used only after reconstruction for a fitted-scale trajectory comparison. Depth is not used. Result images/media derived from these photographs retain this data attribution.

- Additional real photographs: Romuald Perrot, [Avignon Hotel des Monnaies](https://github.com/rperrot/ReconstructionDataSet/tree/4264089c791f7174e7f3657b22b80aac3668924e/AvignonHotelDesMonnaies), [CC BY-NC 3.0 Unported](https://creativecommons.org/licenses/by-nc/3.0/). Eleven originals are pinned by repository commit, byte count and SHA-256 in `tools/demo_manifest.json`. `tools/download_demo.py` retrieves only this sequence and verifies every file. Preview images and the exported facade point cloud are derivatives with the same attribution and noncommercial data terms; the original images are not bundled in this repository. No ground-truth surface geometry or camera poses were supplied.

Version/date note: dependency/API documentation was checked during implementation on November 14, 2026. Installation is pinned in requirements.txt; future releases may change APIs or wheel availability.
